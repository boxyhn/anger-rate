# AngerRate — 구현 계획 / 2026-09-05

## 확정한 요구
사용자는 자신의 언어가 거칠어지는 순간을 숫자로 알아차리고 스스로 쿨다운하고 싶다. macOS 메뉴 막대 수치, 최근 30분 변화와 상승 이유, 100 도달 알림 1회, 시간 감쇠가 핵심이다. Codex와 Claude Code에서 직접 보낸 메시지를 모든 세션에 걸쳐 감지한다. 한 대에서 독립적으로 동작하며 여러 Mac 연결은 선택적이다. 연결된 Mac은 점수 이벤트를 합산한다. 초기 진단은 사용자가 이미 로그인한 Codex/Claude CLI로 과거 메시지를 분석하고 개인별 표현·강도·근거·점수 기준표를 제안한다. 사용자가 확인·수정 후 적용한다. 별도 API 키/회원가입 없음. 외부 분석 전송은 이번 사용자에게 허용되었으며, 배포 앱은 초기 진단 화면에서 전송 내용을 설명한다.

## 설계 선택
SwiftUI + AppKit + Foundation, macOS 13 이상. 외부 패키지 의존성 없음. 기본 UI는 차분한 시스템 색·둥근 숫자와 약간의 따뜻함. 캐릭터/호흡/콘텐츠 추천/메시지 차단은 제외. 실제 감정의 진단이나 확률로 표기하지 않는다.

점수는 표현별 가중치 + 근접 반복 가산, 지수 감쇠(기본 반감기 5분), 0–100으로 제한한다. 약한 재촉은 작게, 직접 모욕은 크게. 100 도달 알림 후 50 이하가 되어야 재무장. 첫 수집과 재시작 과거 재생은 알림을 소급 발송하지 않는다. 인용/코드/도구 결과/에이전트 메시지/주입 지침을 제외한다. 언어적 문맥 필터에는 한계가 있음을 UI에 짧게 설명한다.

개인화는 표현 인식과 가중치를 조정한다. 많이 욕했다고 기준을 무한히 관대하게 만들지 않는다. AI 출력은 고정 JSON 스키마와 수치 범위로 검증하고 사용자 검토 전에는 적용하지 않는다. 원문은 분석할 때만 메모리에 올리고 앱 저장소/동기화에는 원문을 쓰지 않는다.

기기 연결: 사용자가 선택한 동기화 폴더(iCloud Drive 등)에 기기별 점수 이벤트를 원자적으로 저장한다. 각 기기의 안정 ID, 이벤트 중복 제거, 동일한 활성 기준 공유, 마지막 동기화 상태를 표시한다. 동기화 전달은 해당 폴더 제공자의 속도에 따르므로 즉시 일치를 보장하지 않는다. 앱은 서버/열린 포트 없이 한 대만으로 작동한다.

## 순서와 검증
1. 핵심 모델·점수·세션 파서 — 실제 형식의 합성 fixture, 중복/감쇠/알림 재무장/제외 테스트.
2. 읽기 전용 세션 스캐너·CLI 개인화 — 로그 파일 tail, 회전/부분행/기존 기록 처리, CLI 도구 비활성화, timeout, JSON 검증.
3. 메뉴 막대·패널·설정·초기 진단 기준표 — 초기/진행/오류/감지 중지/알림 거부 상태, VoiceOver, 키보드.
4. 로컬 저장·선택적 동기화 — 원문 없는 payload, 파일 충돌/오래된 이벤트/기기별 안정 ID, 두 가상 기기 통합 테스트.
5. .app/.dmg 빌드 및 설치 안내 — swift test, release build, 번들·실행 smoke, 배포 문서.

## 배포 경계
로컬 .app/.dmg 제작과 실행 검증까지 진행. Developer ID 서명·Apple notarization은 계정/인증서가 있어야 가능하다. 공개 저장소 업로드나 배포 서버 게시까지 임의 수행하지 않는다. 사용자의 실제 대화/개인 기준은 Git에 넣지 않는다. 원격 장치에 앱 설치·동기화 폴더 선택 전에는 두 실제 Mac 연동 완료라고 주장하지 않는다.
