불꽃 애니메이션을 유지하면서 메뉴바의 상시 CPU 사용량을 줄인 프리뷰 업데이트입니다.

## 변경 사항
- 프레임마다 이미지를 교체하던 타이머를 제거하고, 캐시한 불꽃 프레임을 Core Animation으로 반복 재생합니다.
- 점수별 움직임 속도와 일시정지·재개 시 진행 상태를 유지합니다. 동작 줄이기와 화면/시스템 잠자기 중에는 재생을 멈춥니다.
- Apple Silicon에서 비활성 모니터에도 정적 아이콘을 표시합니다.
- 세션 파일 크기만 조회해 불필요한 확장 속성·소유자 정보 읽기를 줄였습니다. 감지 주기와 점수 계산은 유지합니다.
- 참고·수정한 RunCat Neo 코드의 Apache-2.0 고지를 앱에 포함합니다. RunCat 그림은 사용하지 않습니다.

## 성능 확인
같은 Mac에서 RunCat과 함께 30초씩 측정한 결과입니다. CPU 100%는 코어 하나 기준이며 환경에 따라 달라집니다.

| 상태 | AngerRate | RunCat |
| --- | ---: | ---: |
| 변경 전 | 6.23% | 0.80% |
| 변경 후 1차 | 0.93% | 0.83% |
| 변경 후 2차 | 0.83% | 0.77% |

전체 데스크톱의 WindowServer CPU 증가도 관찰되지 않았습니다. 자세한 방법과 한계는 `docs/PERFORMANCE.md`에 기록했습니다.

## 설치
`AngerRate-0.1.2.dmg`를 열고 실행 중인 이전 앱을 종료한 다음 Applications로 복사하세요. 앱 버전은 **0.1.2**, 빌드 번호는 **3**입니다.

Apple Silicon(arm64), macOS 13 이상용입니다. 기존 프리뷰와 동일하게 ad-hoc 서명되었으며 **Apple 공증은 받지 않았습니다**. 다운로드 무결성은 `SHA256SUMS.txt`로 확인할 수 있습니다.
