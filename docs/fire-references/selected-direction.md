# 사용자 선택과 추천 방향

2026-09-05 사용자 선호: 5, 13, 51, 65, 89.

실제 다섯 이미지를 나란히 확인했다. 선호 공통점은 두툼한 면, 부드러운 곡선, 위로 향하는 불꽃 끝, 내부와 외부 불꽃의 관계다. 앞서 만든 좁은 물방울이나 임의의 갈래 반복과 차이가 있다.

추천: 51(Solar Fire Bold)을 기본 형태 기준으로, 13(Lewen Design Campfire)의 불꽃을 강한 상태의 형태 기준으로 삼는다. 89(Kathryn Clarke Flame Logo)는 위로 감겨 올라가는 곡선 흐름의 참고다. 5는 강한 불의 동작 참고지만 16px에서 갈래가 복잡해질 수 있다. 65는 단순하나 좌우가 정돈되어 정적인 표지처럼 읽힐 수 있다. 이는 디자인 판단이며 실측 결과가 아니다.

촛불: 51과 같은 곡선 언어를 한 줄기로 단순화. 중간:51의 비대칭 형태. 강함:13의 몇 갈래 불꽃. 89의 상승 곡선을 동작에 참고. 원본 작품을 복사하거나 앱에 적용하지 않았다. 다음 단계는 형태 선택이며 자동 구현하지 않는다.
